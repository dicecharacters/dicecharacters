## Code, forks, and pull requests

Forks and pull requests to this repository are expressly welcome. Fixes and careful extensions that respect the existing structure belong here: in one shared, growing community project.

By opening a pull request, you agree that your contribution may become part of DiceCharacters under the same terms.

## Running your own site or copy

Operating your own public instance (your own domain or hosting of the app) is not forbidden. It does, however, go against the idea of DiceCharacters: an organic community project in one place, rather than many split-off copies.

If something is missing or broken, a pull request or a note here is the better answer than a parallel site.

## Images, graphics, and the name

Logos, images, graphics, and the visual identity of DiceCharacters are copyrighted.

They must **not** be used if you run your own instance — not altered, not as a favicon, not in the UI, and not for promotion. That applies even if you copy the code.

The name “DiceCharacters” stays with this project. A separate instance needs its own name and its own graphics.

## Code, Forks und Pull Requests

Forks und Pull Requests an dieses Repository sind ausdrücklich erwünscht. Verbesserungen, Fehlerkorrekturen und saubere Erweiterungen, die die bestehende Struktur respektieren, gehören hierher: in ein gemeinsames, wachsendes Community-Projekt.

Wer einen Pull Request einreicht, erklärt sich damit einverstanden, dass der Beitrag unter denselben Bedingungen Teil von DiceCharacters werden darf.

## Eigene Website oder Kopie

Eine eigene öffentliche Instanz (eigene Domain, eigener Betrieb der App) ist nicht verboten. Sie widerspricht aber der Idee von DiceCharacters: ein organisches Community-Projekt an einem Ort, statt vieler abgespaltener Kopien.

Wenn dir etwas fehlt oder etwas stört, ist ein Pull Request oder eine Rückmeldung hier die bessere Antwort als eine Parallelseite.

Logos, Bilder, Grafiken und das visuelle Erscheinungsbild von DiceCharacters sind urheberrechtlich geschützt.

Sie dürfen bei einem eigenen Betrieb **nicht** verwendet werden — auch nicht verändert, als Favicon, in der Oberfläche oder zu Werbezwecken. Das gilt unabhängig davon, ob der Code selbst kopiert wird.

Der Name „DiceCharacters“ soll für dieses Projekt bleiben. Eine eigene Instanz braucht einen eigenen Namen und eigene Grafiken.
